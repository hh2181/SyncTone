# MiSans variable font

The Windows application uses an unmodified local copy of `MiSansVF.ttf`.
Obtain it from the official MiSans distribution and place it in this directory
before building. Font binaries are ignored by Git and are not offered as
standalone downloads.

The wght axis in the current local font spans 150..700, with Regular 330 and
Medium 380. Skia creates variable instances for the requested weight.
