# 均衡器

Android 与 Windows 从 0.7.6 起支持应用内十段 EQ。通过侧边栏“均衡器”，或展开播放器后的“音效”按钮进入。

- 固定中心频率：31.25、62.5、125、250、500 Hz，以及 1、2、4、8、16 kHz。
- 每段目标增益 −12 至 +12 dB，调节步进 0.1 dB。可拖动滑条、输入数字或使用加减按钮；Windows 还可用方向键，Shift + 方向键为 0.5 dB。
- Android 将十段分为两组，Windows 在足够宽时十段并排、保存方案位于右侧；窄窗口自动重新排列。
- 曲线横轴为对数频率，纵轴为 dB。点击曲线可查看该频率的响应，并选中最近频段。
- 保存多个命名方案，点选即可应用。删除方案保留当前调节；“重置”恢复当前十段平直，不删除保存的方案。
- 关闭 EQ 为旁路。参数与方案保存在应用数据目录，重启后恢复，不改写音乐文件。

## 曲线与实际声音

两端使用同一套联合校准串联 IIR 算法，同时考虑中心频率及其对数中点，补偿相邻频段之间的影响。
曲线直接由处理音频的滤波器系数计算，保留模型中存在的小幅起伏，没有用平滑曲线掩盖响应。
0.1 dB 是目标参数的步进，不是目标与最终频响误差的上限。

“自动预留音量空间”默认开启：模型存在提升时自动降低前级，为音频峰值留余量。
前级值会在页面显示，并计入响应曲线，所以整条曲线可能比频段目标数值低。该开关可自行调整。
曲线描述 EQ 本身的线性响应，不包括播放器音量、系统音效或耳机／扬声器的响应。
纵轴会根据输出响应与前级基线调整显示范围，0 dB 为参考值，不固定在图表中间。曲线上方直接显示前级值，填色相对前级基线绘制，刻度数值仍包含前级衰减。

采样率显示来自实际音频处理器。“等待应用”表示新参数尚未进入处理，暂停时会在恢复播放后应用。
切换方案或增益时，处理器使用约 40 ms 的交叉淡化以减小突变；连续操作合并为最新目标。

Android 使用 Media3 自定义 PCM 处理器，按解码后的实际采样率设计系数。超出该采样率有效范围的频段会停用并提示。
Windows 保留 libVLC 解码和播放控制，通过 S16N PCM 回调接入共同的 DSP，再由 JavaSound 输出到默认音频设备；本版该路径为 **48 kHz／16 bit／立体声**，不提供独占或压缩音频直通。
Android 的本次 EQ 处理链同样采用 PCM 16 bit，内部滤波计算使用 Double。

模型、接入位置与核验细节见[后端研究记录](equalizer-backend-research.md)。
