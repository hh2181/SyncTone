# SyncTone 0.5.0

- Android 与 Windows 版本统一为 `0.5.0`。
- 使用项目提供的新应用图标，包含 Android 自适应启动图标、Windows EXE 与窗口图标。
- Android applicationId 保持 `app.synctone.music`，versionCode 递增到 `6`。
- 本次保留现有播放器布局、进度条和同步协议 v2。

## 下载文件

- `SyncTone-Android-0.5.0-release.apk`：Android 8.0+。
- `SyncTone-Windows-0.5.0-x64-portable.zip`：Windows x64 便携版，包含 Java 与 VLC 运行库。
- `SHA256SUMS.txt`：上述文件的 SHA-256 校验值。

Windows 需解压整个 `SyncTone` 文件夹再启动。发布包不包含开发机的曲库、播放记录、
配对身份或日志。旧便携版用户的数据位于原程序旁的 `data/` 文件夹，请保留备份。

Android 与 `0.4.0` 使用同一应用 ID 和签名，可以覆盖安装；更早的 `dev.salt.replica`
包名属于另一应用，无法直接覆盖。首次启动附带的音频为纯音测试样本，可自行导入音乐。

## 验证

- Android 51 项与 Windows 70 项测试通过；Android Lint 无错误。
- Android Release APK 的包名、版本、自适应图标与签名已校验。
- Windows EXE 版本信息为 `0.5.0`，便携版实际启动通过。
- 实际 MP3/FLAC 解码、暂停、拖动定位、音量和自然结束检查通过。

## 已知限制

- 手机主动连接部分 Windows 网络环境超时的问题仍需排查。
- Android Release 延续已有本机开发签名，尚未切换为独立正式发布密钥。
- Windows 程序未做 Authenticode 签名。
- 项目尚未选定整体开源许可证；第三方字体与运行库适用各自的条款。
