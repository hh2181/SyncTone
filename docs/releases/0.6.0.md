# SyncTone 0.6.0

Android / Windows 新增联网同步歌词搜索、预览和下载。入口为“歌词设置 → 联网下载歌词”。

- 酷狗 KRC 逐字歌词与 LRCLIB 同步 LRC，支持保留翻译、罗马音和逐字时间。
- 搜索关键词可编辑，结果显示歌手和时长，可预览歌词类型后保存。
- 可开启缺少歌词时自动匹配；默认关闭，匹配须同时满足歌名、歌手及 2.5 秒内的时长差。
- 下载内容进入原来的歌词高亮与滚动界面，离线持久保存，不修改音频文件。
- 两端共享圆角搜索窗口和结果卡片，沿用主题色、暗色模式和共用按钮。
- 支持恢复原歌词，网络异常不影响本地播放；换歌和新搜索会取消旧请求。

实现架构与使用说明见[联网歌词说明](../online-lyrics.md)。

## 验证范围

2026-10-29：两端定向运行 6 项关键用例，覆盖 KRC 时间戳、翻译与离线重读、无效／过大输入、
版本匹配、单源故障、切歌取消、保存目标绑定，以及 LRCLIB 搜索内容复用。

真实联网检查：酷狗日语歌曲搜索返回 5 个候选，下载并解析 60 行逐字歌词，增强 LRC 重读后逐字时间保持一致；
LRCLIB 搜索返回 19 个同步候选，选中内容可解析为 59 行歌词。检查仅输出行数，没有保留第三方歌词样本。

共享界面使用合成歌词完成 390×844 浅色搜索与 960×720 暗色预览的渲染和人工检查。
Android Release 构建含 R8 和关键 lint 检查；本机没有连接 Android 设备，未做手机实机播放或安装验证。
Windows 已生成 x64 便携运行目录；没有开展整库扫描、批量联网或长时间性能测试。

## 仍有的限制

歌词来源覆盖不完整，网络服务可能暂时不可用。手动搜索可调整关键词或切换来源。
本次发现 LRCLIB 按 ID 再查询部分记录时可能返回 HTTP 503；实现优先复用搜索响应中的完整同步 LRC，避免重复查询。
尚未接入 QQ QRC／网易 YRC，也未新增歌词覆盖数据的跨设备传输。
