# SyncTone 0.7.0

Android 与 Windows 新增完整的侧边栏“歌词更新”页面，替代此前的下载弹窗。
按已确认的设计使用统一 18 dp 圆角卡片、蓝色主色及绿色完成状态，保留播放器和侧边栏的原有风格。

- 搜索与预览：可筛选并多选本地音乐，按单曲搜索多来源候选，核对相似度、歌手和时长后预览并自由选择。
- 匹配设置：原文／罗马音／翻译内容及顺序、相似度、时长误差、逐字要求、翻译／罗马音要求、来源开关及优先级、已有歌词策略。
- 批量更新：固定启动时规则，逐首匹配；可暂停、继续或结束，保留已完成项；不合要求的结果进入待确认，可单曲补选。
- 页面动画：三个分页使用 HorizontalPager，在 420 ms 非线性过渡中同时保留新旧卡片，支持点击和滑动。
- Android 避免翻页手势被侧栏抢走；歌词更新页面仍可用菜单或左边缘打开侧栏。
- 歌词文件及 Windows 数据库保留内容类型与顺序，兼容旧数据；批量更新 Windows 歌词时不逐首重读整库 SQL 元数据。

当前真实来源为酷狗与 LRCLIB，QQ／网易云仍待接入。
详细使用、存储和限制见[联网歌词说明](../online-lyrics.md)。

## 验证

2026-10-29：Android 23 项定向测试、Windows 14 项定向测试通过，覆盖现有歌词解析、设置迁移、顺序持久化、
旧数据库读取、相似度、来源优先级、逐字检查、保留本地歌词、暂停取消与继续、任务规则固定和手动补选。

实际 Compose 页面完成 1100×820 搜索页、390×844 暗色设置页及横向切换中间帧检查；
中间帧同时存在移出页与移入页，位置分别为 -845 px 与 207 px（页宽 1052 px）。

真实联网检查：酷狗返回 5 个候选、解析 60 行逐字歌词，增强 LRC 重读后逐字时间一致；
LRCLIB 返回 19 个同步候选、所选结果解析为 59 行歌词。未批量抓取真实曲库，未持久保存第三方歌词测试样本。

Android 没有连接实机，本次不宣称完成手机安装和播放验证。没有开展整库扫描或长时间压力测试。

## 注意

设置改变用于下一次批量任务；正在运行或暂停的任务继续使用启动时的规则。
进度仅保留于本次运行，关闭应用后已保存歌词不会丢失，但需重新选择并启动未完成任务。
歌词来源的可用性和覆盖范围由外部服务决定；批量更新不包含跨设备传输。
