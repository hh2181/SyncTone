# SyncTone 0.7.1

移动端歌曲列表统一以“播放统计”的歌曲排行为设计基准。

- 首页推荐、全部歌曲、专辑／艺人／歌单／收藏详情、播放队列和歌曲统计共用 `MusicListRow`。
- 统一 24 dp 圆角列表容器、39 dp 封面及 9 dp 封面圆角、13 sp 歌名与 11 sp 次要信息。
- 固定序号列宽，普通歌曲与当前歌曲的封面、文字保持对齐，取消首页独有的紧凑行布局。
- 时长并入艺人信息行，给长歌名和“更多”按钮留出空间；统计页保留播放次数及累计时长。
- 列表分隔线、空状态容器、浅色／暗色样式共用，保留原有非线性按压反馈和页面动画。
- 播放队列使用实际队列顺序展示及选择歌曲。

列表组件位于 `app/src/main/java/dev/salt/replica/ui/MusicListComponents.kt`，平台播放器和统计模型由各页面传入。
后续添加同类歌曲列表时应复用这些组件，避免另外维护一套尺寸和字体。

## 验证

Android 编译、Release 构建和 lint 检查通过。
使用实际共用组件完成 390 dp 浅色及 320 dp 暗色、1.3 倍字体的人工渲染检查，
涵盖长歌名、日文、未知艺人、三位序号、当前歌曲和更多操作。
本轮没有运行无关的歌词、网络或批量同步测试；一次性预览程序与截图在检查后清理。
本机没有连接 Android 设备，未宣称完成实机安装或触控验证。
