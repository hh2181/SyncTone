# SyncTone 0.7.2 — Android / Windows

自 GitHub 上的 0.5.0 起，双端新增侧边栏“歌词更新”：联网搜索、预览、匹配设置和批量更新。

- 支持酷狗 KRC 逐字歌词与 LRCLIB 同步 LRC，保留逐字时间、翻译和罗马音，并可调整内容顺序。
- 批量任务支持暂停、继续和结束；可设置来源优先级、相似度、时长误差与已有歌词策略。
- 歌词保存在本机，重启后可离线使用；不修改音频文件。匹配设置与使用说明见[联网歌词说明](../online-lyrics.md)。
- Android 同类歌曲列表统一布局，并修复点歌与播放服务队列恢复问题。

## 下载与升级

- Android：`SyncTone-Android-0.7.2-release.apk`，支持 Android 8.0 及以上，沿用原签名。
- Windows：`SyncTone-Windows-0.7.2-x64-portable.zip`，完整解压后运行 `SyncTone.exe`。
- 随附 `SHA256SUMS.txt`。升级 Windows 版前请备份旧版 `data` 文件夹，再迁移到新便携版目录。

歌词来源的覆盖范围和可用性由外部服务决定。批量任务进度不跨应用重启保存，已应用的歌词保持不变。
本版尚未实现两台设备之间传输歌词覆盖数据；局域网连接在部分网络环境下仍有已知限制。

## Android 点歌修复

修复首页和全部歌曲中，列表已有歌曲但点击后无法切换播放的问题。

- 按歌曲 ID 在 Media3 的实际播放队列中定位，目标不在队列中时重新建立曲库队列并开始播放。
- 连接到仍在运行的播放服务时，从服务恢复实际队列，避免把新曲库或旧偏好的索引用于另一份播放队列。
- 连接播放器时立即读取当前歌曲、播放状态和播放模式，避免重新进入应用后把当前歌曲显示成第一首。
- 初始化队列时保存具体歌曲 ID；播放队列中的点选也通过歌曲 ID 执行。
- 导入新音乐时建立完整曲库队列，保留从第一首新增歌曲开始播放的行为。
- 保留 0.7.1 的列表布局、圆角、配色与按压动画。
