# SyncTone Android 0.7.3

优化安卓专辑／艺人详情和播放统计的卡片过渡，保留原有卡片式布局与配色。

- 专辑／艺人卡片和展开层去掉描边，保持干净的边缘。
- 容器和封面在大部分过渡中保持圆角，接近全屏时再平滑收至页面边缘。
- 详情封面上下渐变随展开进度连续变化，收回时先淡出，再与原卡片封面交接。
- 统计卡片采用专辑详情的 520 ms 展开／300 ms 收回曲线；容器直接向目标边界移动，封面保留轻微弧线。
- 统计详情保持最终布局坐标，封面目标位置在运动中固定，消除边测量边变换形成的反馈。
- 统计封面在过渡期间由一个图层绘制，完成后在相同位置交回静态封面，去掉末段交叉淡入和二次缩放。
- 共享元素卡片不再叠加按压缩放，保留点击反馈，避免按下时捕获缩小后的边界、返回时又突然放大。
- 统计背景不再于每帧创建／撤销模糊层，减少动画末段的图层切换。

本次只更新 Android，版本号 0.7.3（versionCode 11）。

## 验证

- Release 构建、签名及版本检查通过；lint 无错误，89 条现有警告。
- 6 项针对性测试通过，覆盖容器与封面的端点、窄屏运动边界、圆角保留、曲线收敛、反向中断及渐变淡出。
- 在连接的 MIX 2S（1080 × 2160）上覆盖安装 Release APK，保留曲库和设置，并核对已安装包与导出包的 SHA-256。
- 实机检查专辑／艺人展开与收回、统计歌手／专辑卡片、二级详情往返和图表返回。
- 对专辑返回渐变、统计封面抵达与收回末段进行录屏逐帧检查；检查后清理临时视频、截图及重复构建 APK。

没有运行无关的网络、歌词或曲库扫描测试，也没有新增音乐或测试曲库。
