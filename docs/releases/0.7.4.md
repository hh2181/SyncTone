# SyncTone Android 0.7.4

专辑／艺人详情和统计卡片改为全程圆角：从原卡片圆角平滑变化为展开后的 28 dp 圆角，
全屏停留时继续保留圆角，返回时再连续恢复原卡片形状。详情封面和容器使用相同的展开圆角，
避免最后几帧转为直角。

保留 0.7.3 的运动曲线、稳定封面交接、无描边卡片与连续淡出的封面渐变。
本次只更新 Android，版本号 0.7.4（versionCode 12）。

验证：6 项针对性动画测试、Release 构建和签名检查通过，lint 无错误（89 条现有警告）。
已在连接的 Android 设备覆盖安装，并检查专辑详情及统计详情的全屏圆角和返回；临时截图检查后清理。
