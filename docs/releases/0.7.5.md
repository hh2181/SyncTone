# SyncTone Android 0.7.5

- 封面下方的歌词预览从固定 12 sp 改为按逻辑宽度选择 16–20 sp，次要歌词至少 14 sp；保留系统字体缩放。
- 预览使用封面与播放控件之间的剩余空间；短屏或大字体时适当缩小封面，先为歌词与控件留出空间。
- 预览原文最多两行，罗马音／翻译最多各一行，长文本省略显示，点击仍可进入完整歌词页。
- 歌词更新的分页到达最左端后，将剩余的右滑距离交给侧边栏；其他分页优先翻页，最左页头部也允许右滑打开侧栏。
- 专辑／艺人详情和统计详情的多行大标题使用 34 sp 行高，避免长专辑名换成两行后字形挤在一起。

本次只更新 Android，版本号 0.7.5（versionCode 13）。

- Release 构建和 APK 签名通过，lint 无错误（89 条现有警告）。
- 在当前连接的 1220 × 2712、480 DPI 设备上覆盖安装，检查原文／罗马音／翻译预览，以及最左页右滑开侧栏、左滑进入设置、从设置右滑返回搜索页。
- 用用户指出的同一个日文长专辑名核对两行标题行距，保留原字号与两行截断规则。
- 保留当前系统显示设置；测试截图、UI 转储及重复构建安装包检查后清理。
