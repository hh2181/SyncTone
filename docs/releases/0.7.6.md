# SyncTone 0.7.6

双端加入十段均衡器，Android versionCode 14，Windows 便携版版本同步为 0.7.6。

## 功能

- Android／Windows 增加侧边栏“均衡器”入口，播放器“音效”按钮连接到同一页面。
- 沿用蓝色、绿色及统一圆角卡片，Android 两组五段，Windows 宽窗口十段并排、右侧保存方案。
- −12 至 +12 dB、0.1 dB 微调，支持拖动、数字输入、加减按钮及桌面键盘操作。
- 共用联合校准串联 IIR 模型，响应曲线按音频处理器使用的系数与采样率绘制，并包含自动前级余量。
- 保存、切换、删除多个命名方案；重置当前参数不会删除方案。预设文件包含模型版本，使用原子替换保存。
- 处理参数在音频线程之外设计，约 40 ms 交叉淡化应用；均衡器关闭后旁路。

## 验证

- 6 项专项单元测试在双端均通过：已确认的频点组合、实际 PCM 与曲线一致性、左右声道独立、旁路及静音、不同采样率的稳定性／余量、预设恢复及坏文件保留。
- Windows 实际 MP3／FLAC 解码已接入自定义 EQ；暂停、进度跳转、音量与自然结束通过。
- Windows 独立便携包的私有 JVM／音频输出、实际 PCM EQ、播放中旁路、暂停及方案恢复通过。
- Android MIX 2S 真机完成 44.1 kHz 处理状态、侧边栏入口、滑条、0.1 dB 按钮、保存及重启读取、删除与重置检查。测试方案已清除并恢复旁路。
- 检查了桌面、移动和 320 dp 深色／放大字体排版，修正了文字颜色和标题留白。Android lint 为 0 错误、89 个现有警告。

## 处理格式

Windows 本版通过 VLC PCM 回调与 JavaSound 使用默认输出设备，处理格式为 48 kHz／16 bit／立体声。
Android 使用实际采样率的 PCM 16 bit 处理链，低采样率音频会停用超出范围的频段。
不将界面曲线称为硬件输出的实测结果；它与共同 DSP 的理论传递函数一致，音频 PCM 测试已核对该处理结果。

更新保留已有曲库、歌词、统计和连接数据。Windows 升级前保留原目录的 `data` 文件夹。
