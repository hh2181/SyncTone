# SyncTone 0.7.7

本次 GitHub 发布包含自 0.7.2 以来的双端十段均衡器，以及 Android 卡片过渡、歌词预览排版和手势修复。
均衡器支持 −12 至 +12 dB、0.1 dB 微调、多个命名方案、自动前级余量与实时响应曲线，详见[均衡器说明](../equalizer.md)。

## 本版修正

- 修正均衡器纵轴：按实际输出响应、0 dB 参考及前级基线自适应范围，避免自动余量使曲线下移后，图表仍强制以 0 dB 居中。
- 在曲线顶部直接显示“输出响应 · 含前级”和当前前级衰减，说明滑条目标增益与输出曲线之间的关系。
- 填色改为相对前级基线绘制，减少整片衰减区域对频段调节形状的干扰。
- 坐标范围、曲线和填色基线同步过渡；重置后收回旧范围。纵轴标签按实际文本高度居中，适配不同缩放。
- 使用 1 kHz +7.6 dB 场景检查自动前级开／关、重置、移动及窄屏深色布局。未改变滤波算法或实际音频处理。

Android 与 Windows 共用图表修复；Android versionCode 15。Windows 音频处理格式仍为 48 kHz／16 bit／立体声。

## 下载与升级

- Android：`SyncTone-Android-0.7.7-release.apk`，支持 Android 8.0 及以上，沿用上一版签名，可覆盖安装。
- Windows：`SyncTone-Windows-0.7.7-x64-portable.zip`，完整解压后运行 `SyncTone.exe`；升级前请备份原目录的 `data` 文件夹。
- `SHA256SUMS.txt` 提供两个下载文件的 SHA-256 校验值。
